# Tech steering

- Node.js 22+, ESM, no runtime dependencies. Tests with `node --test`.
- Every module stays importable without a DOM or a network, so tests are cheap.
- Data model: a project record is a plain object; the report is a pure function of records.
- HTML is generated by string templates with escaping at the boundary, never by innerHTML.
- CLI exit codes: 0 ok, 1 usage error, 2 nothing found.
